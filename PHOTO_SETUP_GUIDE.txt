NORBOOZ CROCHET - SIMPLE PRODUCT PHOTO GUIDE
============================================

1. Photograph near a bright window in daytime. Avoid flash and strong yellow ceiling lights.
2. Use the same simple background for the main photo of every product: cream, white, beige, or light timber.
3. Take the main photo square or leave enough space so it can be cropped square.
4. For each item, take 4-6 photos: front/main, second angle, close-up stitches, size reference, lifestyle photo, and colour/custom option when useful.
5. Recommended main website image: about 1200 x 1200 px, JPG or WEBP.
6. Use meaningful filenames without spaces, for example crochet-capybara.jpg.
7. Copy the files to C:\xampp\htdocs\norbooz_crochet_v2\assets\images\products\
8. In Admin Panel, set Image path to assets/images/products/crochet-capybara.jpg

BACKGROUND REMOVAL
A clean natural background is usually better for handmade crochet than removing every background. Use background removal mainly when the original background is distracting. Keep lifestyle and detail photos natural.
